# Reconstruction Archive

These files preserve historical reconstruction evidence and earlier architecture notes. They are not active ARAMF instructions.

Some documents intentionally mention the former lowercase `aramf/` directory,
the temporary reconstructed Python backend, or superseded paths. Current
repository authority is defined by `aramf_setup/AGENTS.md`,
`aramf_setup/PROJECT_STATUS.md`, `aramf_setup/memory/decisions.md`, and the
active repository rules. Generated managed projects have a separate uppercase
`ARAMF/` control plane.
